# 🔐 Digital Escape Room - Lab 204

A fun and interactive **Digital Escape Room Quiz** built as a college web development project using HTML, CSS, and JavaScript.

## 📖 Description

You are trapped inside **Computer Lab 204**! The lab computer has malfunctioned and all the doors are locked. Answer 8 multiple-choice questions correctly to collect keys, unlock doors, and escape before time runs out!

## ✨ Features

- 🚪 **4 Doors / Stages** — Binary, Web, Logic, and Riddle challenges
- 🧩 **8 Multiple-Choice Questions** — 2 questions per door
- ❤️ **3 Lives System** — Lose a life for each wrong answer
- 🔑 **Key Collection** — Earn keys by clearing doors
- 🏆 **Score System** — +100 for correct, -10 for hints
- 🔥 **Streak Tracker** — Track consecutive correct answers
- ⏱️ **5-Minute Countdown Timer** — Escape before time runs out!
- 💡 **Hint System** — Get help at the cost of points
- 💻 **Terminal Messages** — Computer-style feedback messages
- 📊 **Progress Bar** — Visual progress indicator
- ✅❌ **Green/Red Answer Feedback** — Correct answers glow green, wrong answers shake red
- 🕵️ **Player Name Input** — Personalized experience
- 🎖️ **Final Rank** — Get ranked based on performance
- 📝 **Mission Report** — Full review of all answers at the end
- 📱 **Responsive Design** — Works on desktop, tablet, and mobile

## 🛠️ Technologies Used

- **HTML5** — Page structure
- **CSS3** — Styling and layout
- **JavaScript** — Game logic and interactivity

No frameworks, libraries, or external dependencies.

## 🚀 How to Run

1. Download or clone this repository.
2. Open `index.html` in any web browser.
3. That's it! No server or build step needed.

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/digital-escape-room.git

# Open in browser
# Simply double-click index.html or open it in your browser
```
